# Object Oriented Programming Lab in C++

This repository contains C++ programs developed as part of the Object Oriented Programming laboratory.

## Overview

The programs in this repository demonstrate core Object Oriented Programming (OOP) concepts using C++. The lab focuses on building a strong foundation in programming through practical implementation of concepts.

## Topics Covered

- Basic C++ programs (I/O, loops, conditions)
- Functions and control structures
- Arrays and matrices
- Classes and Objects
- Constructors and Destructors
- Function Overloading
- Operator Overloading
- Inheritance
- Templates (Function & Class)
- File Handling
- Exception Handling

## Project Structure

All programs are implemented as individual `.cpp` files with descriptive names.

## How to Run

1. Compile the program:
   g++ filename.cpp

2. Run the program:
   ./a.out
